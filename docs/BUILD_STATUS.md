# مملكة الراعي الملكي

هذه النسخة تُبنى مباشرة في مستودع GitHub وتعمل كصفحة ويب ثابتة عبر GitHub Pages.

## الأنظمة الموجودة في المحرك

- زمن مركزي: 300 ثانية للدورة اليومية و600 ثانية للفصل.
- فجر/نهار/غروب/ليل مع موجات ليلية.
- الفصول الأربعة والطقس الموزون وتأثيره على الحركة والزراعة.
- اقتصاد وموارد وحفظ/تحميل محلي.
- مبانٍ متعددة مع ترقيات القلعة.
- زراعة بأربع مراحل، محصول شتوي، مطر وري.
- ماشية: أبقار، أغنام، ثيران، تكاثر، حلب، جز صوف، تغذية وإجهاد.
- مسلخ وحظيرة حجر صحي وصيد.
- حراس، رتب، تدريب، أوامر ومجموعات.
- حرس ملكي وتشكيلات وحماية أولوية للملك.
- عربة ملكية وحالة ركوب/ترجل.
- أسلحة قريبة وبعيدة ومدفعية بأنواع قذائف متعددة.
- فيزياء مقذوفات ومؤثرات وجسيمات وحريق وارتجاج كاميرا.
- إدخال لمس/سحب/تكبير ومؤشر تفاعل.
- صوت مولّد داخل المتصفح دون ملفات صوت ضخمة.
- مستويات جودة وأساسيات culling/particle budgets للحفاظ على أداء الهاتف.

## ملاحظة التطوير

الأسلوب الفني الحالي يجمع الأصول الموجودة في المستودع مع رسم Canvas طبقي procedural. المرحلة التالية الطبيعية هي استبدال الرسومات الإجرائية بأوراق Sprite مرسومة بالكامل لكل حالة حركة، مع إبقاء نفس واجهات الأنظمة والبيانات.
