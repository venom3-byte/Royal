# مملكة الراعي الملكي
نسخة Web قابلة للعب مبنية من الصفر داخل GitHub.

## التقنية
TypeScript + Vite + Phaser 3.90.0. Phaser هو إطار 2D مخصص للمتصفح ويدعم Canvas/WebGL والإدخال الموحد للمس والماوس ولوحة المفاتيح.

## الأنظمة الموجودة
Game Loop، فصل State/Simulation/Rendering، دورة يوم وليلة 5 دقائق، الفصول 10 دقائق، طقس متغير، توليد عالم، زراعة أساسية، حيوانات، حراس/عمال، أعداء ليليون، قتال، عملات، حفظ محلي، كاميرا جانبية، وتحكم لمس.

## الهدف المعماري
التوسعة التالية مخصصة للزراعة المتقدمة، التجنيد والترقيات، المدفعية، الاقتصاد، الحملات، AI LOD، Object Pool، Spatial Partition، Web Audio، IndexedDB، والأصول الفنية النهائية.

المراجع التي بُنيت عليها القرارات: Game Programming Patterns، MDN Game Development، WebGL2/WebGPU Fundamentals، Discover three.js، وPhaser 3 الرسمي.
